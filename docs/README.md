# Onix docs

Pointers to the documentation kept in this directory.

## For users

- **[GUIDE.md](./GUIDE.md)** — the full user guide. Start here if you're
  using onix day-to-day.
- **[PLAYBOOK.md](./PLAYBOOK.md)** — quick command matrix. A copy/paste
  cheatsheet for the core flows.

## For contributors

- **[MODULE_PATTERN.md](./MODULE_PATTERN.md)** — the standard pattern for
  creating an Onix module (plugin).
- Repo-root **[CONTRIBUTING.md](../CONTRIBUTING.md)** — how to get patches
  in.
- Repo-root **[ROADMAP.md](../ROADMAP.md)** — the living "Road to 10/10"
  list of project work.

## Design notes & working plans

In-flight specs and working plans live under [`design/`](./design/).
They're transient: once the work lands, the doc is deleted, archived, or
merged into one of the permanent docs above.

- **[design/SEGMENTS_SPEC.md](./design/SEGMENTS_SPEC.md)** — authoritative
  spec for the `seg@seg@alias` syntax and `segments.toml` schema (implemented).
- **[design/SEGMENTS_PLAN.md](./design/SEGMENTS_PLAN.md)** — PR-by-PR
  implementation plan that landed the spec (implemented).
- **[design/TODO.md](./design/TODO.md)** — main-package coverage push
  (working plan).
